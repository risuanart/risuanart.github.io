    迪士尼／皮克斯怎麼選圖？

    迪士尼跟皮克斯是「自己帶圖創作」最受歡迎的主題之一，但不是每張圖的難易度都一樣——像小美人魚愛麗兒、阿拉丁茉莉公主這種手繪平面風格的經典，跟魔髮奇緣樂佩公主、怪獸電力公司這種立體風格的作品，一堂課畫起來的難度差很多。整理一個簡單的判斷方式，幫你先抓個底，再傳圖片給我們確認詳細評估。

    2D 手繪平面風格

    白雪公主、仙履奇緣、睡美人、小美人魚、美女與野獸、阿拉丁、公主與青蛙這幾部，都算是 2D 手繪平面風格，主要強調手繪線條感，色塊相對單純。

    這類風格比較適合一堂課完成，新手也容易上手。

    3D 立體風格

    魔髮奇緣、冰雪奇緣、勇敢傳說、海洋奇緣這幾部可以簡單劃分成 3D 立體風格，皮克斯、夢工廠、索尼的作品也幾乎偏向這一類（像怪獸電力公司的大眼仔）。

    立體風格的光影層次比較多，一堂課要做出高精緻度的成品會比較吃力，光是把形狀畫完整就要花不少時間，更不用說細節。

    自己怎麼簡單評估

    看色塊的部分：是單色＋線條（偏平面），還是多色＋線條不清晰（偏立體）。

    如果一張臉需要用很多種膚色組合堆疊出來，就是偏立體的畫風，光是把膚色層次堆出來就比較花時間，更不用說再畫很多細節。

    第一次畫畫的同學怎麼選

    不建議挑選需要多堂課才能完成的圖，因為成品可能會跟想像中有落差，反而影響完成的滿意度。先從一堂課能完成的風格開始，比較不容易踩雷。

    這只是大概的劃分

    這篇文章的評估方式只是協助大家稍微判斷選圖的難易度，不是絕對標準——同一個角色的不同再製圖、衍生圖，會有各種風格與形式，實際難易度跟完成時間，還是要把圖片傳給我們評估最準確。

    作品能不能完成，取決於你對選圖的耐性，只要有心想完成，沒有經驗絕對不是問題。
